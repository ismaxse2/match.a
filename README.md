# MATCH.A

Лендинг агентства бренд-партнёрств и коллабораций в wellness. На сайте представлены услуги, продукты и команда. Форма заявки пока проверяет поля локально. [Бриф проекта](docs/MATCHA_BRIEF.md)

Стек — Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 и Motion. Компоненты и сценарии взаимодействия проверяются в Storybook.

## Архитектура

Проект использует FSD-lite. Зависимости направлены от маршрутов и секций к функциональности и общим компонентам.

- `src/app` — главная страница, маршрут `/legal` и общий layout.
- `src/widgets/landing` — секции лендинга, навигация и контент.
- `src/features/inquiry` — форма заявки и её валидация.
- `src/shared` — переиспользуемые UI-компоненты и глобальные стили.
- `public` — статические изображения.

## Команды

- `npm ci` — установить зависимости.
- `npm run dev` — запустить сайт на порту 3000.
- `npm run storybook` — запустить Storybook на порту 6006.
- `npm run lint`, `npm run typecheck`, `npm run format:check` — проверки кода.
- `npm run build` — собрать сайт.
- `npm run start` — запустить собранный сайт.
